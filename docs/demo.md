# Демонстрация: 5 минут + 3 минуты вопросов

1. Показать разметку кандидата: границы, два состояния клапанов, мостик Р-543,
   разрыв №6—17. Объяснить статус pending.
2. Выполнить python scripts/review_packet.py, показать строку отчёта и область PDF.
   Отсутствующие источники остаются ошибкой, пока не подключены.
3. После настройки API выполнить python -m gap_agent chat, запросить проверку
   манифеста. Показать AgentResult, trace_id, отчёт и журнал LLM/MCP.
4. Запросить пример из двух узлов и трубы. Показать цель и хеш. Сначала отказаться
   от подтверждения. Для другого запроса подтвердить точный план именем оператора.
5. Показать реальный результат GAP или фактический отказ лицензии. Smoke
   подтверждает только техническую интеграцию, не производственный фрагмент.
6. Повторить execute того же run_id — результат без новых native вызовов.
7. Показать python scripts/evaluate_llm.py: парафразы и отключённую LLM. Если API
   не настроен, показать NOT_ASSESSED, а не заготовленный успешный ответ.

Производственный сквозной сценарий требует подтверждения, исходников и проверенного
native профиля. Его завершение — независимый экспорт и сравнение. До этого
предъявлять производственный сценарий как выполненный нельзя.
