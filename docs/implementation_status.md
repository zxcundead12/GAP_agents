# Выполненные изменения и внешние зависимости

После повторной проверки обновлённого проекта продолжена третья часть:
Groq → типизированная задача → локальная валидация/план → MCP → результат и отчёт.
Окружение Python восстановлено для текущего компьютера. Модель задана в конфигурации,
ключ отсутствует; живой тест Groq отложен по указанию пользователя.
IPM удалён пользователем и будет установлен после решения вопроса с OpenServer.

| Задача | Что реализовано | Что нужно извне |
|---|---|---|
| Выбор/разметка | Кандидат УДР: 21 узел/порт, 20 ветвей, 2 источника, 11 клапанов | Решение преподавателя о фрагменте и подсчёте минимумов |
| Все таблицы | 6 CSV, включая источники и границы | Подтверждение содержания |
| Манифест/источники | SHA, области, единицы, подключение перемещённых исходников | PDF, легенда, 80 параметров, рабочие состояния |
| Спорные места | Пакет 8 вопросов, физическая и потоковая связность | Реальные инженерные решения |
| Сравнение/отчёт | Подключены к агенту, формируется review_packet | Реальный независимый экспорт |
| ПО/лицензия | Текущая диагностика и API-ошибки отдельно от старых журналов | Доступ OpenServer |
| Технический пример | Исполняемый smoke с сохранением, чтением и повтором | Успешное выполнение в ПО |
| Производственный адаптер | Компилятор, guarded worker, SetValue, шаблон и нормализатор | Проверенный профиль и принятая семантика клапанов |
| MCP | 6 инструментов, stdio, планы и receipts | Рабочее окружение на машине запуска |
| Настоящая LLM | Groq, явная модель gpt-oss-20b, строгая задача и обработка ошибочных ответов | Локальный ключ и отдельный живой прогон |
| Подтверждение | Консоль, действия/цель/хеш, отдельная команда | Решение оператора по плану |
| AgentResult/журнал | Общие схемы, статусы, trace_id, скрытие настроенных секретов до сериализации | Живые результаты для защиты |
| Проверки | Unit, реальный MCP, live eval-парафразы/disabled LLM | Живой прогон модели после настройки |
| Сборка/демо | Переносимые README, setup/run-agent, demo.md | Воспроизведение с полным комплектом |

Статус проверок — outputs/verification/summary.json. Инженерная приёмка, live LLM
и реальный native build не объявляются выполненными по искусственным unit-тестам.
